How a row is valued

Implied value = TVL × the sector multiple × a growth multiplier × a maturity multiplier. The sector multiple is the median market-cap / TVL of the token-bearing protocols in the same category, read out of this snapshot — never a number written by hand. Growth is the protocol’s seven-day TVL change, clamped to −50…+100%. Maturity rewards time spent with no token: the longer a protocol has run without one, the closer its launch is priced. An implied value is this entry’s own claim, never a prediction of whether or when a token launches.
